Privacy Policy

Last updated: November 18, 2026

This policy covers "The Tale Keeper Publisher", an internal tool used only by the owner of the YouTube channel The Tale Keeper (@TheTaleKeeperTV).

Data we access

With the channel owner's authorization through Google OAuth, the tool accesses the owner's own YouTube channel to upload videos, set thumbnails, edit video metadata and schedules, and read YouTube Analytics reports for that channel. It does not access data from any other user.

How we use it

The data is used only to publish the channel's videos and to analyze the channel's performance. It is not sold, shared with third parties, or used for advertising.

Storage and security

OAuth tokens are stored privately on the owner's own computer with restricted file permissions. Analytics data is kept only as long as needed for the channel's reports.

YouTube and Google

This tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at Google security settings.
